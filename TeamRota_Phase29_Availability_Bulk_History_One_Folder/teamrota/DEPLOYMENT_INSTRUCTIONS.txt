TEAMROTA PHASE 26 — CLEAN SHORT-PATH DEPLOYMENT

1. Extract this ZIP.
2. Upload the folder named: app26
3. In Vercel set Root Directory exactly to: app26
4. Framework Preset: Next.js
5. Build Command: npm run build
6. Install Command: npm install
7. Output Directory: leave blank
8. Redeploy without Build Cache.

This short folder name prevents Vercel's 128-character Serverless Function path error.
The full application is included inside app26 (app, lib, public, supabase, package.json, middleware.ts, tsconfig.json, vercel.json).
