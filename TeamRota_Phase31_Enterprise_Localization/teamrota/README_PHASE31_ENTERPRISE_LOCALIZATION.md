# Phase 31 — Enterprise Localization

This release expands the centralized UI translation layer for English, Kurdish (Sorani), Arabic, and Urdu.

It covers navigation, availability, organization chart, rota patterns, leave, bulk historical leave, overtime, holidays, timesheets, employee administration, profile/password screens, notifications, Google Drive archive, AI assistant controls, buttons, labels, filters, placeholders, status text, and validation-style messages rendered in the interface.

Arabic, Kurdish, and Urdu use RTL layout. English uses LTR layout.

No database migration is required.
